# FLASK

홈페이지의 소스·화면·이미지·설정·주문 기록까지 이 폴더로 이동했습니다. **현재 홈페이지 수정 대상은 이 FLASK 폴더의 코드**입니다. 메인 폴더에 소스 복사본은 없습니다.

## 실행과 관리

- 외부 공유: 이 폴더의 **서버_켜기.cmd** 더블클릭. 현재 공유 서버가 켜져 있으면 반복 실행하지 않습니다.
- 상태 확인·종료: 이 폴더의 **서버_관리.cmd** 더블클릭.
- Python 환경은 메인 `.venv`를 유지합니다. 실행 파일은 이 폴더의 `.venv`가 있으면 먼저 사용하고, 없으면 상위 메인의 `.venv`를 사용합니다.
- DB 설정은 이 폴더의 `.env`입니다. 기존 비밀번호와 SECRET_KEY, runtime/order_requests.sqlite3를 삭제·덮어쓰지 않습니다.
- 자동화로 백그라운드 실행한 공유 로그는 `runtime`에 있습니다. 접속 주소 안내는 `출력물/접속정보/`를 확인하세요. 과거 임시 주소는 재시작 후 사용할 수 없습니다.
- 새 Cloudflare 주소가 발급되면 `출력물/바로가기/MobleKurly_현재주소_바로가기.zip`이 자동 생성됩니다. 팀원은 ZIP을 풀고 MK 아이콘이 파일에 내장된 `모블 컬리 웹 열기.exe`를 더블클릭하면 됩니다. 별도 설치는 필요하지 않으며 `.url`은 실행 파일이 차단될 때 사용할 예비 수단입니다.

프로젝트 메인 폴더에서 수동 실행:

```powershell
# 로컬 개발용: http://127.0.0.1:5000/
.\.venv\Scripts\python.exe FLASK/app.py
# 외부 공유용: 로컬 5001 + 출력되는 HTTPS 주소
.\.venv\Scripts\python.exe -X utf8 -u FLASK/share.py
```

두 명령을 동시에 반복 실행할 필요는 없습니다. 외부 팀원에게는 127.0.0.1이 아니라 공유 실행에서 출력된 최신 HTTPS 주소를 전달합니다. 팀 DB PC와 네트워크 연결도 유지해야 합니다.

## 회원·적립금 기능 병합 (2026-10-21)

회원가입·로그인·마이페이지·회원 5% 할인·출고 완료 주문 1% 적립·적립금 사용/사용 취소·재주문을 추가했습니다. 기존 떠 있는 장바구니, 상품 사진, 스크롤 위치 유지, 물류 상세, 광고 슬라이드와 주문 중복 방지는 유지합니다. 본문 장바구니에서도 사진과 함께 수량 변경·삭제가 가능합니다.

현재 팀 DB에는 users와 orders.user_id·배송지·points_used가 이미 있어 추가 SQL을 실행하지 않았습니다. 기존 products.price는 바꾸지 않고 회원 할인 단가를 주문 품목에 기록합니다. 자세한 범위·검증·남은 주의 사항은 `문서/변경기록/회원_적립금_장바구니_병합_20261021.md`를 확인하세요. MFC 결산의 적립금 차감 반영은 별도 작업입니다.

## 코드와 자료 위치

- `app.py`, `db.py` 등: Flask 서버·주문·DB 연결.
- `templates/`, `static/`, `data/`: 화면·이미지·스타일·상품 안내.
- `runtime/`: 주문 중복 방지 기록·공유 실행 로그. 다른 PC에 복사하거나 초기화하지 않습니다.
- `tools/`, `tests/`: 실행·관리·검사 도구.

- `문서/사용안내/`: 서버 실행·외부 접속·상품·결제 화면 안내.
- `문서/변경기록/`: 홈페이지 병합·장바구니·중복 주문 변경 기록.
- `출력물/발표자료/`: PPT·발표 대본·순서도.
- `출력물/브랜드/`: 홈페이지 로고와 기본 아이콘. 관리자 아이콘은 MFC/출력물/아이콘으로 이동.
- `출력물/바로가기/`: 서버 실행 때마다 최신 임시 주소용 MK 아이콘 바로가기 ZIP을 자동 갱신합니다.
- `출력물/공유본/`: 홈페이지 소스 배포 ZIP.
- `백업/`: 과거 소스·로고·발표 제작·정리 기록.

## 검사 및 새 설치

프로젝트 메인 폴더에서 `.\.venv\Scripts\python.exe -X utf8 FLASK/tools/run_checks.py`로 전체 Python 검사를, `node --test FLASK/tests/*.mjs`로 화면 로직 검사를 실행합니다. Python 검사에서는 실제 DB 접속을 차단합니다.

새 PC 설치 시 메인 폴더에서 `py -m venv .venv`로 환경을 준비하고 `.\.venv\Scripts\python.exe -m pip install -r FLASK/requirements.txt`로 의존성을 설치합니다. `.env`가 없는 새 설치에서만 FLASK/.env.example을 FLASK/.env로 복사하고 담당자가 팀 DB 설정과 비밀키를 입력합니다. 기존 서버의 .env를 예시로 덮어쓰지 않습니다. SQL 초기화 덤프를 다시 실행할 필요는 없습니다.

과거 안내·변경 기록에는 당시의 메인 폴더 경로가 남아 있습니다. 현재 위치·명령은 이 README와 메인 폴더 안내를 우선하세요.
