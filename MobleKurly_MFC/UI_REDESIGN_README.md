# MobleKurly 작업 관리 탭 / 관리자 탭 UI 최종 시안 반영

기준: `MobleKurly_MFC_Main1_ErrorBin_Merged_Source.zip` (오류수거함·CCTV·PDF가 합쳐진 main1 소스)

## 수정 파일 (3개)
- MobleKurlyDashboard/DashboardFrame.cpp: 두 탭 머리글 통일, 8개 상태 카드(온도·습도 분리), 오류 수거함 간소화, 관리자 CCTV 왼쪽/결산 오른쪽, 부모 탭 클릭 좌표 및 관리자 CCTV 다시 연결 위치, 인라인 결산 창 표시·숨김.
- MobleKurlyDashboard/DashboardFrame.h: 관리자 탭 인라인 결산 창 핸들 선언.
- MobleKurlyDashboard/SettlementIntegrated.cpp: 기존 결산 모듈을 팝업과 임베디드 창 모두로 사용할 수 있게 생성 방식 추가. **기존 DB 쿼리·날짜/지역 필터·그래프·PDF 저장 함수는 보존.** 관리자 탭에서는 최초 표시 시 자동 DB 조회 시작. 작업 결산 팝업도 기존처럼 유지.

## 적용된 배치
- 작업 관리 탭: 좌측 주문·처리·출고 이력, 가운데 실시간 검사 카메라·간소화 오류 수거함·재고, 우측 온습도 그래프·높이가 같은 두 로그·작업 결산. 위 상태 카드 8개 동일 폭 및 비상정지 우측 유지.
- 관리자 탭: 전체 CCTV 왼쪽(축소), 매출 결산 모듈 오른쪽(상시 화면 내 표시). 매출 기간·지역/상세 탭 및 PDF 저장은 결산 모듈의 실사용 기능을 그대로 재사용.
- 탭 이름: `작업 관리 탭`, `관리자 탭`.

## 확인할 사항
1. Visual Studio 2022에서 솔루션 빌드 (이 환경에서는 Windows/MFC 라이브러리 빌드 불가).
2. 작업 관리 탭의 출고/재시도/긴급 정지/비우기/이력/재입고/작업 결산 버튼 동작 검증.
3. 관리자 탭으로 이동해 CCTV 영상 표시, `다시 연결`, 결산 자동 조회/기간 변경/지역 변경/상세 탭, `PDF 저장` 검증.
4. `config.ini`와 DB 접속 환경은 기존 사용하던 설정 유지.

참고: 최종 이미지 시안은 레이아웃 기준이며, 실제 결산 콘텐츠는 **메인의 기존 결산 모듈 컨트롤을 직접 내장**하므로 그래픽(예: KPI 증가율 표시)은 시안의 임의 숫자가 아니라 원래 코드의 실제 DB 값/기능에 따라 다릅니다.
