# MobleKurly UI 재수정

기준: 직전 UI 승인 통합본. 주문·재고·출고·CCTV·PDF 계산/저장 등 데이터 및 장치 처리 함수 변경 없음.

- 작업 관리 탭 / 관리자 탭 모두 상단 한 줄: 로고, 두 탭, 로그인 사용자, 로그아웃, 날짜, DB 연결 상태.
- 작업 관리 탭의 화면 전체에 적용됐던 불필요한 +45px 이동 제거. 클릭 좌표도 같이 수정함. 기존 비상 정지 유지.
- 관리자 탭의 결산 표시가 잠시 후 사라지는 페인팅 문제를 위해 부모 윈도우에 WS_CLIPCHILDREN 적용.
- 관리자 결산 자식 창 안의 모든 컨트롤이 폭 800픽셀 범위에 들어오도록 반응형 재배치. 보라/흰색 톤 배경 적용.
- 결산은 별도 버튼 없이 관리자 탭에 표시, PDF 저장만 기존 버튼 사용.

### 검증 제한
정적 코드 점검 및 ZIP 무결성 테스트만 실시. Windows MFC 실제 빌드와 화면 표시 테스트는 수행하지 못함.
